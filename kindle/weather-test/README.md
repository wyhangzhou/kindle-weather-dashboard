# 两次自动刷新测试

适用于已经通过单次 RTC 测试的 Kindle 4 Black / 固件 4.1.2。该入口仅运行两次下载和显示，中间一次 30 秒休眠，随后恢复原来的 Wi-Fi、无线开关和屏保设置并返回 Home。保留原生阅读框架，不设置开机任务。两次刷新可能下载同一张云端图片；实际下载、显示和休眠次数以日志核对。

将本目录放入 `/mnt/us/extensions/weather-run-test/`，给 `.sh` 执行权限。重新打开 KUAL，选择 **Weather test (2 refreshes)**，准备图出现后 15 秒内拔掉 USB，将实体按键放在左边。天气图保留约 30 秒，然后再次刷新并自动回 Home。若仍插线，取消测试且不设置闹钟。正常网络下约一分钟完成；网络请求各有时限。

处于唤醒状态时，Home 或 **Stop weather test** 会停止运行并恢复设置。休眠中若需要提前恢复，短按电源键，随后 Home；清理会等本次最多 30 秒的闹钟到期。不要通过这个有限测试入口设置 30 分钟周期；旧驱动不能用写 0 取消闹钟，长周期的立即退出仍需独立解决和验证。

`runner.sh --check` 只读检查。`runner.sh --self-check` 短暂关闭 Wi-Fi 并模拟 Home，测试清理和原值恢复，不画图或请求休眠。真正运行需要 Wi-Fi 开启、原生 active 状态、电量至少 20%。日志在 `/mnt/us/kindle-weather/tests/`，最新记录由 `last-weather-test.txt` 指向。返回主页后还需人工检查原有书籍和实体翻页。

`fetch.sh --fetch` 仅下载和更新缓存，不改屏幕或电源。`fetch.sh --current` 返回最后一次已校验的图片路径。每次 HTTPS 请求用用户目录独立 CA 认证服务器，并有连接及总时限、文件大小上限；不跟随重定向、不读取 netrc。专用缓存包含两个完整快照，通过原子替换小型指针文件提交一整组图片和清单，避免 FAT 不支持符号链接的问题。

云端额外提供 `device-manifest.txt`：12 个固定 ASCII 键值字段。设备不执行下载内容，拒绝重复/未知/缺失字段、异常时间和尺寸、过期天气、相对于缓存倒退的天气时间、下载长度或校验和不符、错误 PNG 头尾。当前认证由 HTTPS/TLS 完成；原生 MD5 仅检测同一清单和图片的传输一致性，不承担密码学认证。JSON 及纯文本清单同时保留 SHA-256，供现代客户端独立核验；设备本身没有 SHA-256 命令。

任何请求、格式或校验失败都不替换已保存的缓存。`--current` 可读取过期缓存供恢复显示，图片上的日期和更新时间仍表明其陈旧状态；新下载必须通过有效期检查。有限测试失败会记录原因并恢复 Home，持续断网重试尚未由此实现或验证。

重新生成准备图：在仓库根目录运行 `.venv/bin/python kindle/weather-test/render_screens.py`。实际连续刷新、唤醒后实体 Home 退出和长期运行，仍需设备日志和用户观察确认。


## 提前唤醒退出测试

**Wake and exit test** 只显示缓存天气并安排一次 120 秒唤醒；它不重复刷新。准备画面出现后 15 秒内拔 USB，天气图显示后等约 5 秒，短按电源键唤醒，再按 Home。脚本应恢复原来的闹钟及 Wi-Fi/屏保设置并回到主页。未操作时约 2 分钟自动返回。此测试用于验证中途退出能取消尚未到期的唤醒，真实休眠后的这条路径尚待用户和日志验证。

`exit-test.sh --check` 只读检查；`--self-check` 在不画图、不设置未来闹钟、不休眠的情况下验证 Home 取消及设置恢复。闹钟状态仅保存在 `/mnt/us/kindle-weather/state/alarm-exit-test`，成功恢复后删除；失败保留供检查，不直接覆盖其他来源的新闹钟。

### K4 原生 RTC 恢复实现及限制

`alarm.sh` 只支持本项目已核对的 K4/MC13892、MC34708 寄存器布局。读取 PMIC 的独立秒计数来判定报警时间；该计数不等于系统 UTC，不能把当前 Unix 时间直接写进去。标准 `rtc1/wakealarm` 的驱动不填 `enabled`，设置时也忽略它，因此不能把读空或写 0 当作硬件取消成功。恢复时核对闹钟所有权，然后禁用报警比较器，恢复保存的报警时间/日期与启用位，并逐项读回。系统时钟及 PMIC 时钟计数器保持不变。

这个固件的 `/dev/pmic` 写 ioctl 忽略传入的位掩码。实现必须先读整寄存器、在用户态合并位值，再写回整值；写入范围严格限制为报警寄存器 21/23，禁止写中断掩码或其他电源寄存器。原型第一次掩码验证失败后已撤销其影响，正确实现的不休眠未来闹钟→原值恢复检查已通过，中断配置前后相同。原型故障和恢复证据保留在主工作区的私有研究记录；正式休眠后的提前退出仍需实际验证。
